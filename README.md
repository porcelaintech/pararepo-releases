# Pararepo

Pararepo 帮助本地编程 Agent 在独立的 Git 工作树中完成需求。你可以在 Mac 的看板上跟踪进度，在原来的 Agent 对话中收到结果。

## 下载和安装

已公开的 macOS 安装包会列在 [Releases](https://github.com/porcelaintech/pararepo-releases/releases)。下载前请核对对应版本说明中的芯片和系统要求。首发面向 Apple 芯片 Mac。使用项目管理功能需要本机已有 Git 和一个受支持的编程 Agent，例如 Codex 或 Claude Code。

1. 在版本附件中下载 `.dmg`，打开后把 **Pararepo.app** 拖入「应用程序」。
2. 弹出磁盘映像，从「应用程序」打开 Pararepo，在「本机连接设置」中连接你的 Agent，按宿主提示完成信任或重开会话。
3. 在本地 Git 项目的 Agent 对话中提出一个小需求。打开 Pararepo 看板查看进度，回到原对话查看结果。

遇到安装或连接问题，可以通过 [Issues](https://github.com/porcelaintech/pararepo-releases/issues) 提供 macOS 版本、芯片型号和复现步骤。
