# Pararepo for macOS

Pararepo lets coding agents work in separate Git worktrees. Follow a project's progress on the Mac dashboard and get the result in the agent conversation where you requested it.

Pararepo 帮助编程 Agent 在独立的 Git 工作树中完成需求。你可以在 Mac 看板上跟踪项目进度，在原来的 Agent 对话中查看结果。

## Install the English edition

1. Open the English DMG and drag **Pararepo.app** into **Applications**. When upgrading or switching languages, replace the app in its existing folder to keep using your projects and agent connections.
2. Eject the disk image and open Pararepo from Applications. If macOS blocks the first launch, use the PDF installation guide inside the DMG.
3. Open **Local connections**, connect your coding agent, and follow its prompts. With Git installed, open a local project in the agent and request a change. Follow the work on the dashboard and return to the original conversation for the result.

## 安装中文版

1. 打开中文版 DMG，把 **Pararepo.app** 拖入「应用程序」。升级或切换语言时，请在原安装位置替换应用，继续使用已有项目和 Agent 连接。
2. 弹出磁盘映像，从「应用程序」打开 Pararepo。如果 macOS 阻止首次打开，可参阅 DMG 内的 PDF 安装指南。
3. 在「本机连接设置」中连接编程 Agent，按宿主提示完成设置。安装 Git 后，在 Agent 中打开本地项目并提出一个需求。在看板上查看进度，回到原对话查看结果。
